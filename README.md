## 🚀 Overview

Agentic Scope is an end-to-end corporate formation, compliance, and autonomous technology ecosystem built for non-resident entrepreneurs and international businesses.

### Core Solutions:
- **UK LTD Formation:** Official Companies House incorporation, London Registered Office, Director Service Address, Biometric ID Verification, and HMRC UTR.
- **USA LLC Formation:** Wyoming, Delaware, Florida, and Texas LLC filing, IRS EIN registration without SSN, Operating Agreements, and FinCEN BOI reporting.
- **International Banking & Gateways:** Assisted setup for Wise Business, Tide, Airwallex, Payoneer, Stripe, and PayPal Business.
- **Technology & AI Systems:** Autonomous 24/7 AI Sales & Customer Support Agents, WhatsApp Cloud API automation, custom CRM/ERP business platforms, and Next.js web applications.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js 14](https://nextjs.org/) (App Router, Static Site Generation)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom Specular Sheen Glassmorphism
- **Icons:** Lucide React
- **Animations:** Lightweight GPU Canvas Shaders + Framer Motion
- **Centralized Data:** Fully decoupled datasets in `/data/` (`site.ts`, `packages.ts`, `services.ts`, `providers.ts`, `faqs.ts`, `blog.ts`, `navigation.ts`)

## 🏃 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build & Launch
```bash
npm run build
npm run start
```
